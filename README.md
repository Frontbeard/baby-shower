# Baby Shower de Mateo

Invitación digital con sobre animado, cuenta regresiva, galería, lista de regalos y confirmación por WhatsApp.

## Cómo verla en local

Abrí `index.html` en el navegador, o desde la carpeta del proyecto:

```bash
npx serve .
```

## Configuración importante

En `script.js`, editá:

```js
whatsappNumber: "54911XXXXXXXX"  // código país + número, sin + ni espacios
```

Ese número recibirá las confirmaciones de asistencia.

## Publicar en Vercel (gratis)

1. Subí el proyecto a GitHub.
2. En [vercel.com](https://vercel.com) → Importá el repositorio.
3. Deploy sin configuración extra (sitio estático).
4. URL ejemplo: `baby-shower-mateo.vercel.app`

## Publicar en GitHub Pages

1. Subí el repo a GitHub.
2. Settings → Pages → Source: branch `main` / carpeta `/` (root).
3. URL ejemplo: `usuario.github.io/baby-shower`
